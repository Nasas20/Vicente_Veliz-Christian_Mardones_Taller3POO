# Proyecto

## Descripcion:
Sistema de gestión desarrollado en Java para un juego de rol basado en magia. Permite administrar magos y sus hechizos, calcular puntuaciones según el tipo de elemento, y generar reportes y rankings. Los datos se cargan y guardan desde archivos de texto plano, asegurando la persistencia entre ejecuciones.
